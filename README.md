# Dr. Malak Ismail — Executive Portfolio Website

Executive portfolio website for Dr. Malak Ismail — Marketing, Communications & Media Leader.

**Live site:** https://malakismail86.github.io/malak-ismail-portfolio/

## Structure

```
index.html          Main page
css/style.css        All styling
js/script.js          Mobile nav + footer year
images/               Photos, company logos, media thumbnails
assets/               Downloadable CV (PDF)
```

## Making updates

1. Edit files directly on GitHub (click the pencil icon on any file), or clone the repo locally and push changes.
2. Any push to the `main` branch automatically republishes the live site within a minute or two via GitHub Pages — no separate deploy step needed.
3. To replace a photo or logo, upload a new file to the `images/` folder with the same filename, or update the `src` path in `index.html` if the filename changes.
4. To update the downloadable CV, replace `assets/Malak_Ismail_Executive_CV.pdf` with a new file of the same name (or update the link in `index.html` if the filename changes).

## Local backup

A complete copy of this site (all HTML, CSS, JS, and image/asset files) has been provided as a downloadable ZIP, independent of GitHub, so the project is not dependent on any single platform.
